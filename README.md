# my-first-web-project

My first web development project, built as a hands-on exercise while learning the fundamentals of HTML, CSS, and JavaScript.

The goal of this project was to understand how these three technologies work together to create an interactive webpage, with a particular focus on JavaScript fundamentals, DOM manipulation, and event-driven interactions.

## ✨ Features

- Light and Dark Mode: An interactive button that switches between two visual themes.
- Dynamic Button Text: A playful Batman/Bruce Wayne reference that changes depending on the active theme.
- JavaScript Interaction: Event listeners, conditional logic, and dynamic updates to HTML elements.
- CSS Custom Properties: Reusable variables that define different colors for light and dark themes.
- Responsive Styling: Improved spacing, typography, and button layout for different screen sizes.
- Accessibility Improvements: Keyboard focus indicators, descriptive button labels, and reduced-motion support.
- Learning List: A webpage displaying the programming languages and web technologies I'm exploring.

## 🛠️ Technologies Used

- **JavaScript** — Programming logic, DOM manipulation, event handling, and interactive functionality.
- **HTML5** — Document structure, semantic elements, classes, IDs, and accessibility attributes.
- **CSS3** — UI styling, visual design, responsive layouts, custom properties, theme customization, and accessible color transitions.

## 🧠 JavaScript Concepts Practiced
Through this project, I practiced:

### Variables and Constants:
- Declaring constants using const.
- Storing references to DOM elements and their properties.

### DOM Manipulation:
- Selecting elements using document.querySelector().
- Accessing document.body.
- Adding and removing CSS classes with classList.toggle().
- Reading an element's classes using className.
- Updating displayed content using textContent.
- Updating HTML attributes using setAttribute().

### Functions and Events:
- Creating callback functions.
- Handling click events with addEventListener().
- Understanding the role of this inside a regular event listener callback.

### Conditional Logic and Operators:
- Using if and else statements.
- Applying defensive checks before interacting with DOM elements.
- Comparing values using the strict equality operator (===).
- Using the assignment operator (=).
- Concatenating strings using (+).

### Debugging and JavaScript Behavior:
- Displaying information with console.log().
- Using 'use strict'.
- Observing how JavaScript changes the webpage without reloading it.

## 🏗️ HTML Concepts Practiced
- Understanding the basic structure of an HTML document using <!DOCTYPE html>, <html>, <head>, and <body>.
- Using headings, paragraphs, unordered lists, list items, and buttons.
- Understanding the differences between class and id attributes.
- Organizing content using semantic HTML elements such as <main>.
- Linking external CSS stylesheets using <link>.
- Connecting external JavaScript files using <script> and the defer attribute.
- Configuring document metadata, including character encoding, language, viewport, and page title.
- Adding accessibility attributes such as aria-label.
- Using <noscript> to provide information when JavaScript is disabled.

## 🎨 CSS Concepts Practiced
- Applying styles using element, class, and ID selectors.
- Understanding the CSS box model, including box-sizing, padding, margins, and borders.
- Styling typography, colors, lists, and buttons.
- Defining reusable CSS custom properties with :root and var().
- Creating light and dark themes using CSS classes.
- Understanding CSS inheritance and the font property.
- Working with responsive sizing using max-width, min-height, vh, and clamp().
- Using border-radius to customize element shapes.
- Creating smooth visual effects using CSS transitions.
- Improving keyboard accessibility with :focus-visible and outline.
- Respecting reduced-motion preferences using CSS media queries.


## 🚀 Getting Started:
1. Download or clone this repository.
2. Keep index.html, First Project.css, and First Project.js in the same folder.
3. Open index.html in your web browser.
4. Click the theme-switching button to alternate between light and dark modes.
5. Open the browser's Developer Tools to explore the JavaScript console output.
6. No external libraries, dependencies, or installation are required.
