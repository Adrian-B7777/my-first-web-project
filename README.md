# my-first-web-project

This is my first web development project, built as a hands-on exercise while learning the fundamentals of HTML, CSS, and JavaScript.
The goal of this project was to understand how these three technologies work together to create an interactive webpage.


✨ Features
- Light and Dark Mode: An interactive button that switches between two visual themes.
- Dynamic Button Text: A playful Batman/Bruce Wayne reference that changes when the theme is switched.
- Custom Styling: Colors, fonts, lists, and button styles using CSS.
- CSS Variables: Custom properties to manage theme colors.
- Learning List: A simple page displaying the programming languages and web technologies I'm exploring.
- JavaScript Interaction: DOM manipulation, event listeners, and an introductory alert message.

🛠️ Technologies Used
- HTML5 — Page structure and content.
- CSS3 — Visual styling, positioning, and theme customization.
- JavaScript — User interaction and dynamic content.

🚀 Getting Started
1. Download the repository.
2. Keep the HTML, CSS, and JavaScript files in the same folder.
3. Open Primer proyecto.html in your web browser.
4. Click the theme-switching button to explore the interaction.
5. No additional dependencies or installation are required.

📚 What I Learned
- Through this project, I practiced:
- Structuring a webpage using HTML elements and attributes.
- Applying styles using CSS selectors, classes, and IDs.
- Defining and using CSS custom properties.
- Understanding basic CSS positioning.
- Selecting HTML elements with JavaScript.
- Handling click events with addEventListener().
- Modifying element classes and text using JavaScript.
- Separating HTML, CSS, and JavaScript into individual files.
